# Remastered Controls Resistance Retribution

TheOfficialFloW's Remastered Controls Resistance Retribution plugin modified to run on Vita ARK-4

## Installation

Copy the plugin to `ux0:pspemu/seplugins` and follow the ARK-4 [plugin installation documentation](https://github.com/PSP-Archive/ARK-4/wiki/Plugins)

Additionally, ensure the right analog stick isn't mapped to any controls.
This can be done by holding the PlayStation button, opening official settings and unmapping any existing right analog controls.

To enable Infected Mode, create an empty file called `resistance_infected.bin` in `ux0:pspemu/seplugins`

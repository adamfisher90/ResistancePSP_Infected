# Resistance Retribution Infected Mode Plugin

This plugin activates Infected Mode on the Resistance Retribution for the PSP without having to connect to a PS3. It has been tested with the US version of the game (UCUS98668) on ARK-4 for the PSP and the Vita. YMMV with other versions and firmwares.

## Installation

Copy the plugin to `ms0:/seplugins` on the PSP or `ux0:pspemu/seplugins` on the Vita and follow the ARK-4 [plugin installation documentation](https://github.com/PSP-Archive/ARK-4/wiki/Plugins)
